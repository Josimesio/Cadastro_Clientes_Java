# Cadastro_Clientes_Java
Cadastro de Clientes em Java 17 é uma aplicação simples via console para gerenciar clientes, permitindo cadastrar, listar, buscar por CPF, atualizar e remover registros. Os dados são armazenados em arquivo CSV, dispensando banco de dados e facilitando o uso em estudos, testes ou como base para evolução futura em projetos maiores.
